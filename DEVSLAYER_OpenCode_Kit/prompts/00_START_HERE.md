# OpenCode Prompt 00 --- Start Here

Open this repository in OpenCode. Before changing any code, read
`AGENTS.md`, `docs/DESIGN_SPEC.md`, and `docs/IMPLEMENTATION_PLAN.md`.

Your first task is **audit and planning only**: 1. Inspect the
repository, Git status, framework, package manager/lockfile, scripts,
deployment configuration, routes, public assets, current portfolio
content, resume links, and existing tests. 2. Do not assume this
repository is React or that the provided portfolio URL is the same
codebase. Report what you actually find. 3. Create
`docs/REPOSITORY_AUDIT.md` and `docs/CONTENT_AUDIT.md`. Record current
architecture, reusable assets, deployment risks, verified project/social
links, and content needing confirmation. 4. Use the resume snapshot in
`docs/DESIGN_SPEC.md` as one source, but prefer inspecting repository
files for direct URLs and project evidence. Do not invent missing links.
5. Propose the safest migration path to DEVSLAYER. If a framework
migration is needed, explain impact on GitHub Pages/base paths and
deployment before implementation. 6. Run only relevant existing
read-only checks if useful. Do not install packages or modify app files
in this phase.

Finish with: findings, risks, recommended stack, phased plan, commands
run, and unresolved questions. Wait for approval before making
implementation changes.
