# Assets

All SVGs use the profile's shared dark terminal palette: near-black surfaces, neon green accents, muted technical text, and restrained purple highlights.

- `hero-banner.svg` — animated profile identity banner
- `section-divider.svg` — animated circuit-style section separator
- `terminal-window.svg` — terminal frame artwork
- `status-panel.svg` — current engineering focus panel
- `footer-signal.svg` — animated closing signal

Use relative paths from the repository root, for example:

```html
<img src="./assets/hero-banner.svg" width="100%" alt="Abhijeet Dhokne — Engineering Interface">
```

GitHub may restrict some SVG features or animation in certain contexts. The README should remain understandable even when an animation is rendered as a static image.
